# 模型服务设置与输入链路修复记录

日期：2026-10-29

## 修复范围

| 问题 | 修复结果 |
| --- | --- |
| 重选当前服务商覆盖表单；切换服务商丢失地址、模型或沿用错误密钥 | 当前项不再重置，服务商分别保留连接草稿，新服务商不自动沿用其他服务商的密钥 |
| 超时逐字输入被限值改写；执行步数溢出时静默保存旧值 | 保留原始输入，保存时校验，空值和溢出有明确错误提示 |
| 模型、生成和执行设置混用草稿保存与立即落盘 | LLM 配置统一点击保存；外观、权限及安全开关保持即时保存 |
| 连点保存、保存中继续编辑或重置引发状态不一致 | 禁止重复写入；较新的草稿不会被错误标记为已保存；重置期间暂停编辑 |
| 测试连接隐式修改持久化配置 | 探测到的上下文信息先保留在草稿，点击保存后才落盘 |
| 修改配置后旧网络结果覆盖新状态；取消诊断后按钮一直忙碌 | 取消旧任务、检查协程状态，并恢复运行标记 |
| 拉取模型只检查地址非空，异常可能导致状态卡住 | 检查地址和密钥；允许模型名为空时拉取；捕获网络异常并显示结果 |
| 模型列表横向堆积，难以查找、重复项造成选择歧义 | 去重排序，加入搜索和限高懒加载列表；模型 ID 按大小写精确匹配 |
| 重置没有确认；保存失败、跨页面字段错误反馈不明确 | 添加重置确认、未保存提示、错误反馈、加载与保存状态 |
| 加密密钥损坏后，显式保存空密钥仍保留旧密文 | 允许清除损坏密文并切换无鉴权服务 |
| 多个输入通道连续尝试粘贴；输入后立即清空剪贴板 | 无障碍直接设置优先；串行输入；仅保留一次最终剪贴板回退 |
| 后台剪贴板写入被系统拒绝时仍可能粘贴旧内容 | 写入后读回核对内容与本次操作标记；不一致时不发送粘贴按键 |
| 无障碍输入忽略追加和选区语义；先清空再设置触发两次修改 | 一次文本设置完成追加、选区替换或整体替换，并恢复光标 |
| 回退途中失败后改用另一引擎，可能重复部分文本 | 选定一个 shell 引擎后不自动重复输入；不能确认输入时向 Agent 返回禁止盲目重试的提示 |
| 多行 shell 输入使用 Enter，可能提前发送聊天内容 | 多行文本使用直接设置或一次粘贴，避免逐行按 Enter |
| 文本输入成功但 Enter 失败，被当作整次操作失败重试 | 单独返回文本成功和 Enter 结果，提示只重试提交动作 |

## 界面与应用巡检

- 启动图标、应用内标识及通知图标改为统一的手绘轮廓爪印；同步 SVG、PNG 和字标资源。
- 修复浅色主题下聊天页爪印对比度不足。
- 修复 Root 已授权时补开无障碍的按钮被隐藏。
- 设置页处理键盘遮挡和重复窗口边距；模型快捷项增加触摸区域及选中语义。

- 外观与专家设置写入失败时显示错误，避免未捕获异常。
- 设置、关于、技能编辑、技能需求、任务比较页面改用派生滚动状态，减少滚动时不必要的重组。
- 图标导出工具：`python scripts/refresh_paw_icons.py`，依赖 Pillow，读取 `ic_paw.xml` 并同步输出。

## 验证边界

当前未连接 Android 设备，也没有配置可用模拟器，因此没有执行设备界面测试、真实模型服务请求或真机剪贴板测试。不能据此宣称所有系统与输入控件均已验证无缺陷。

设备验收重点：设置保存后重启恢复；服务商切换和取消诊断；窄屏、大字体、软键盘遮挡；中文、表情、多行、追加、选区替换；停止任务后的输入阻断；原剪贴板恢复及输入期间用户修改剪贴板时不被覆盖。重点覆盖 WebView、第三方聊天输入框和后台剪贴板受限的 Android 系统。
