## 兼容性与验证边界

- 正文仍保存在原会话 JSON；新增字段都有默认值，索引不是权威数据，可在丢失或文件版本变化时重建。首次迁移逐个读取旧文件，后续启动复用索引。
- 单会话正文读取预算 16 MB，超限/损坏文件保留损坏备份，避免无限分配内存。摘要分页不会把所有正文留在内存。
- 处理耗时是模型轮次与工具调用的累计耗时，排除会话闲置、人工暂停，也不包括工具间的自适应等待；它不是端到端任务墙钟时间。旧记录无数据时显示未知。
- 图片发送给当前配置的模型服务，模型需支持视觉；不支持时由服务返回错误。使用系统选择器，不申请全盘文件或相册读取权限。
- 资源超预算会返回失败；自动化已经产生的副作用不会因输出超限自动回滚。API 重定向仍需用户填写最终地址。
- 无障碍密码属性不能保证识别所有自绘/纯图片页面。Root、Shizuku、ROM 保活与物理设备帧率不能用 JVM/模拟器冒充实测。
- 本机无已连接设备或已配置 AVD；仪器测试通过 GitHub Actions 的 API 26/35 模拟器矩阵执行。
